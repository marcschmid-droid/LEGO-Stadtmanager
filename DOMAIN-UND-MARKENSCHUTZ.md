# Brick City Manager – Domain & Markenschutz

## Eigene Domain
Die App ist technisch für eine eigene Domain vorbereitet. Aktiviert werden sollte sie erst, nachdem die gewünschte Domain registriert wurde.

Empfohlener Ablauf:
1. Domain registrieren, z. B. brickcitymanager.de.
2. DNS auf GitHub Pages konfigurieren.
3. Im Repository eine CNAME-Datei mit der endgültigen Domain anlegen.
4. Supabase Authentication > URL Configuration auf die neue Domain ergänzen.
5. E-Mail-Redirects und Datenschutzerklärung auf die neue Domain aktualisieren.

Die bisherige GitHub-Pages-Adresse sollte bis zum erfolgreichen Umzug als Fallback erhalten bleiben.

## Markenschutz
Vor einer Markenanmeldung sollte der Name "Brick City Manager" in DPMAregister, EUIPO eSearch/TMview und allgemeinen Suchmaschinen auf identische oder ähnliche ältere Kennzeichen geprüft werden.

Für eine Software-/Web-App kommen typischerweise insbesondere Waren-/Dienstleistungsbereiche für herunterladbare Software und SaaS/Softwaredienste in Betracht. Die endgültige Klassenwahl sollte vor Einreichung geprüft werden.

Eine formale Markenanmeldung kann nicht automatisch aus dem Repository durchgeführt werden: Sie erfordert Angaben des Anmelders, Auswahl des Schutzumfangs und eine gebührenpflichtige Einreichung beim DPMA oder EUIPO.
