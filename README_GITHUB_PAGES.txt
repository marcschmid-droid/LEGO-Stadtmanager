LEGO Stadtmanager – GitHub Pages
================================

Die App ist bereits mit deinem aktuellen Startbestand vorbereitet.

UPLOAD AUF DEM IPHONE:
1. Öffne dein Repository LEGO-Stadtmanager auf github.com in Safari.
2. Tippe auf Add file -> Upload files.
3. Entpacke dieses ZIP vorher in der Dateien-App.
4. Lade ALLE Dateien aus diesem Ordner in das HAUPTVERZEICHNIS des Repositories.
   Wichtig: index.html muss direkt oben im Repository liegen, nicht in einem Unterordner.
5. Commit changes.

GITHUB PAGES AKTIVIEREN:
1. Repository -> Settings.
2. Links im Menü -> Pages.
3. Unter Build and deployment:
   Source = Deploy from a branch
   Branch = main
   Folder = /(root)
4. Save.
5. GitHub erstellt nach kurzer Zeit die Pages-Adresse.

IPHONE-INSTALLATION:
1. Pages-Adresse in Safari öffnen.
2. Teilen -> Zum Home-Bildschirm.
3. Danach startet der LEGO Stadtmanager wie eine App.

ENTHALTEN:
- bestätigter Startbestand aus deiner Master-Excel
- Einkaufsliste/Wunschliste
- Hinzufügen/Bearbeiten/Löschen
- Mengenerhöhung bei gleicher Setnummer
- Stadtbereiche und Zugplan-Hinweis
- CSV Import/Export
- JSON Backup/Restore
- PWA/Offline-Grundfunktion
